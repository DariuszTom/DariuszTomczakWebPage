About

I'm a senior full stack developer working mostly in C# and .NET, with Java and Python when the job calls for it. What I enjoy most is application modernisation: containerising apps with Docker, moving them to the cloud and building the CI/CD pipelines that ship them reliably.

I started in fund accounting at State Street, where automating my own work with Excel VBA turned into a career in software. These days I'm most interested in using AI and MCP servers to streamline development. Outside work I tinker with PC hardware and local LLMs, and build things in .NET, like ReceptyOks and this site.
